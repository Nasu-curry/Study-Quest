# STUDY QUEST — 学習管理RPG

学習をRPGのキャラクター育成のように管理するWebアプリです。HTML / CSS / JavaScript のみで動作し、データはブラウザの LocalStorage に保存されます（サーバー不要）。

## 公開手順（GitHub Pages）
1. `index.html` `style.css` `script.js` `README.md` をリポジトリのルートに置いて push
2. **Settings → Pages** で `Deploy from a branch` / `main` / `(root)` を選んで保存
3. 表示された URL にアクセス（パスはすべて相対、画面遷移は `#` ハッシュ）

## 仕様
- **画面**: ホーム（プロフィール・総合レベル・スキル一覧）／カテゴリー／スキル詳細／学習記録／設定／セーブデータ管理
- **EXP**: 学習1分＝1EXP（全科目共通）。秒単位で蓄積し、スキルごとの合計が60秒に達するたび1EXP
- **レベル**: 上限なし。次のレベルに必要なEXP＝`ceil(100 + 0.5 × 現在Lv)`（Lv1=101, Lv70=135, Lv300=250, Lv800=500, Lv1000=600）。累計EXPから必要EXPを順に消費して算出するため、余剰は繰り越され、複数レベル同時アップも正確
- **総合レベル**: 各スキルの累計EXPの合計から算出（二重加算なし）。スキルのレベルとは独立
- **ランク**: レベルから自動判定（初心者 / 初級卒業 Lv70 / 中級者 Lv300 / 上級者 Lv800 / 極 Lv1000）。設定画面で境界値・名称を変更可能。変更しても記録は変わりません
- **手動EXP加減算**: スキル詳細から可能（履歴に残り、削除すると取り消し）
- **スキル・カテゴリー削除**: 削除される履歴件数と差し引かれるEXPを確認ダイアログで表示

## データ設計
- 累計EXPは「学習履歴の秒数の合計＋手動補正」から常に導出（レベル・進捗・総合値は保存値ではなく共通関数で算出）
- 保存先: LocalStorage キー `studyquest.save`（`{app, version:2, savedAt, data}`）。変更のたびに自動保存し、ヘッダーに「保存中／保存済み／保存エラー」を表示
- 書き出し: `STUDY_QUEST_save_日付_時刻.json`（保存日時・バージョン・サマリー付き）
- 読み込み: 形式・整合性を検証してから確認ダイアログを表示。失敗時は現在のデータを一切変更しません
- 旧バージョン（v1）のデータは自動移行。旧データ `studyquest.v1` は削除せず `studyquest.v1.backup` にも退避します。旧EXPは各履歴に記録されていた値から引き継ぎます（昇格試験・ランク昇格の記録は「記録」として残ります）
